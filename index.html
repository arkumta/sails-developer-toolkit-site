SAILS / TOOLKIT Features
Open-source developer tooling

Build Sails smart contracts with confidence.

Sails Developer Toolkit is an early-stage VS Code extension concept designed to make developing Rust-based smart contracts for the Vara ecosystem more convenient.

Explore on GitHub ↗ Explore the toolkit

Developer workflow, simplified.

The current prototype focuses on basic project discovery, starter code, build checks and simple diagnostics.

01 / DISCOVER

Sails project detection

Scan Rust project manifests for Sails-related dependencies and source files.

02 / START

Service template

Insert a starter service template into the editor to help begin a contract project.

03 / BUILD

Build checks

Run Cargo checks from the editor workflow and review compiler output.

04 / INSPECT

Basic diagnostics

Check for common project structure and Sails macro indicators. This is not a security audit.

Built for the Vara ecosystem.

Our goal is to reduce friction for developers building with Rust and Sails. The toolkit is a work in progress, and the next milestone is reliable extension loading and end-to-end command testing.
